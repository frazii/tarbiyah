### Overview

Tarbiyah is a multi-center management platform for Islamic teaching centers (madrasah / maktab), modelled on School Bytes: enrolment, classes, attendance, fees, hifz and tilawah progress, behaviour (akhlaq), announcements, and events with digital permission slips — plus two Islamic utilities, Adhan timings (AlAdhan API, per-center coordinates and calculation method) and a Qibla locator (device compass + great-circle bearing to the Kaaba). Four roles use one codebase: **Super Admin** (platform), **Center Admin**, **Teacher**, and **Parent**.

The canvas above walks every role's real journey through the shipped screens: visitor → branded sign-in → parent dashboard → child profile, the teacher's roll and the admin's tools, and the super-admin Platform Portal with the mobile view beside it.

### Architecture

The whole app is server-rendered: pages are server components, every write is a server action posted by a plain form, and client JavaScript is reserved for the three things that genuinely need the device — prayer times, the qibla compass, and the mobile nav drawer.

One external service: the AlAdhan API is fetched client-side (no key) using each center's latitude, longitude and calculation method, and also supplies the Hijri date shown across the app.

<Callout id="invariants" tone="decision">

Three invariants hold everywhere: **tenant isolation** is enforced in queries via `centerScope(user)`, not just hidden in the UI (super admins are the only cross-center role); **attendance is one record per student per class per date** (unique index, saves are upserts); and **brand colors below 4.5:1 contrast on white are rejected at save**, so a center can never theme itself unreadable.

</Callout>
